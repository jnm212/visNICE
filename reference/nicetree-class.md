# class to represent a tree for nice hierarchy

class to represent a tree for nice hierarchy

## Slots

- `node`:

  node id

- `pnode`:

  parent node id

- `lab`:

  doc code

- `plab`:

  parent doc code

- `text`:

  nice textual info

- `drugnames`:

  common names for drugs where known

- `lev`:

  level of each node (root node is 0)

- `Nnode`:

  number of nodes in the tree excluding root node

- `Nlev`:

  number of levels in the tree excluding root node

- `doctype`:

  NICE document type
